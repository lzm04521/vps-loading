# ntfy 通道与界面优化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地设计文档六项：ntfy 告警通道、设置页左侧分块菜单重做、告警记录删除/清空、库存每页条数可选（最大 1000）、库存与事件列表展示评测地址、库存供应商筛选多选。

**Architecture:** Tauri 2 桌面应用，Rust 主进程（模型/存储/命令/告警发送）+ React 19 + antd 5 WebView。跨边界 DTO 一律 camelCase，`src/types.ts` 镜像 `src-tauri/src/model.rs`。ntfy 为第 5 个 `Channel` 枚举值，发送走 reqwest，token 存 Windows 凭据管理器。

**Tech Stack:** Rust(edition 2024，已用 let-chains)/ rusqlite / keyring / reqwest；TypeScript / React / antd 5 / i18next / Vitest。

**Spec:** `doc/20261023-设计文档-ntfy通道与界面优化.md`（含事件→Priority/Tags 映射表等取值，执行时一并阅读）。

- `src/i18n/zh-CN.json` 与 `en.json` 键集合始终一致（新增键两份都加）。
