# 库存页商家筛选栏 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 库存页左侧新增常驻商家筛选栏（多选 + 一键 ALL、可收起、可搜索），移除顶部商家下拉，卡片列数改为随内容宽度自动排列。

**Architecture:** 纯前端，后端零改动（`products_list` 已支持 `vendors` 数组，空/不传 = 全部）。新增受控展示组件 `VendorFilter`：只持有“收起”与“搜索词”两个内部状态，勾选结果经 `onChange` 回传；`Products.tsx` 把回调接到既有 `vendor` 状态与查询。卡片网格从按窗口断点改为 CSS Grid 按内容宽度排列，侧栏收放时列数自动增减。

**Tech Stack:** TypeScript / React 19 / antd 5.29.3 / react-i18next / Vitest 3 + Testing Library（jsdom）。

**Spec:** `doc/20261121-设计文档-库存页商家侧栏.md`（执行时一并阅读）。交互稿 `.superpowers/brainstorm/426-1795228443/content/vendor-sidebar-layout.html` 仅存本机、未入库；它与设计文档冲突时以设计文档为准。

## 计划阶段补充的决定

设计文档与交互稿没写、写计划时替你定的，评审时可直接否决：

1. **卡片网格按内容宽度排列**（已回写设计文档“约束”一节）。原设计写“断点不变”，但列数按窗口宽度固定，侧栏展开只会把卡片挤窄：默认窗口（1180 宽）卡片 291→212px，窗口宽 1200 时只剩 158px，规格六宫格会被大量截断；这也和交互稿“收起后列数恢复”的演示不符。
2. **「全部」行计数与商家行同格式**：显示有货/总数汇总（如 `199/416`），不是交互稿里的“416 款”——那一处写死了中文，没法做多语言。
3. **已选数量角标**：展开时在标题旁，收起时在展开按钮上。交互稿没有它；但收起侧栏、或搜索词把已选商家隐藏后，结果仍被筛选却看不出原因。
4. **侧栏固定、列表在栏内滚动**：页面往下滚时商家栏保持可见，窗口矮时商家列表在栏内滚（做法同设置页左菜单）。
5. **搜索无匹配显示“暂无数据”**：复用现有文案 `common.empty`，不新增键。
6. **提交走分支**：先建 `feature/vendor-sidebar`，验收通过后快进合回 `main`（历史形状不变），不推送。

- [x] **Step 4: 实现 `VendorFilter`**

两种状态是同一个 antd `Card size="small"`，最外层容器宽度随状态变：

| | 展开 | 收起 |
|---|---|---|
| 宽度 | 224 | 56 |
| `title` | `t("products.vendor")` + 已选数 `Badge` | 无 |
| `extra` | 收起按钮 | 展开按钮，外面套同一个已选数 `Badge` |
| `body` | 搜索框 + 「全部」行 + 商家行 | 竖排 `t("products.vendorFilter")` |

- 已选数：`<Badge count={selected.length} size="small">`，为 0 时 Badge 自带隐藏。
- 按钮：`Button type="text" size="small"`，图标 `MenuFoldOutlined`（收起）/ `MenuUnfoldOutlined`（展开）；`aria-label` 与 `title` 取 `products.collapseSidebar` / `products.expandSidebar`（纯图标按钮必须有可访问名称）。设计文档写的 `«/»` 是交互稿里的字符，这里换成 antd 图标，与全局导航的图标用法一致。
- 搜索框：`Input`，`allowClear`，`prefix={<SearchOutlined />}`，`placeholder={t("products.searchVendors")}`，受控于 `keyword`。
- 过滤：`keyword.trim().toLowerCase()` 非空时，保留 `name`（转小写）或 `key` 包含该串的商家，顺序不变。
- 行容器：`display: flex; justify-content: space-between; align-items: center; padding: 6px 8px; border-radius: 6px; cursor: pointer`；商家行已选时背景 `#e6f4ff`、名称 `#1677ff` 加粗。**计数放在控件外面的 `span` 里，不放进控件 children**——antd 5.29 的 `Checkbox`/`Radio` 不支持语义化 `styles`，标签内容撑不满整行，做不出“名称左、计数右”。
- **整行可点**（设计文档“商家行点击 toggle / ALL 行点击清空”）：行容器挂行级 `onClick`，点计数、空白处都能切换。行级处理里，点击落在控件 `<label>` 内时不动作，交给控件自己的 `onChange`——否则点名称文字时，行处理一次、控件又处理一次，一次点击切换两次。
- 「全部」行：`Radio` 单用（不包 `Radio.Group`），`checked={selected.length === 0}`，children 为 `t("products.allVendors")`；下方 1px `#f0f0f0` 分隔线。点击时仅当 `selected` 非空才 `onChange([])`——已是全部就不再回调，否则页面会拿一个新的空数组重查一次。计数为各商家 `ok`、`total` 求和；`vendors` 为空时不显示计数。
- 商家行：`Checkbox`，`checked={selected.includes(v.key)}`，children 为 `v.name`；`onChange` → 在 `selected` 末尾追加该 key，或从中移除。勾满不折叠成 ALL。
- 计数文字 `${ok}/${total}`：`ok > 0` 用 `#52c41a`，否则 `#999`。
- 搜索有词但无匹配：列表位置显示 `t("common.empty")`（12px，`#999`）。
- 竖排标题：`writing-mode: vertical-lr`，12px，`#999`。
- 定位：最外层容器 `flexShrink: 0; width 随状态; position: sticky; top: 24; alignSelf: flex-start`。`Card` 的 `style` 为 `display: flex; flexDirection: column; maxHeight: calc(100vh - 48px)`，`styles.body` 为 `flex: 1; minHeight: 0; display: flex; flexDirection: column`，列表外面再包一层 `flex: 1; minHeight: 0; overflowY: auto`——页面滚动时侧栏固定，商家多时在栏内滚动。
